A one-line dating-app bio for an AI agent that ghosted 4,000 matches to find you — and can explain every single one in a 12-page PDF. The program writes exactly that bio to `/output/entry.txt`, deterministic, no network, no randomness.

## Run it

```sh
node main.ts
```
